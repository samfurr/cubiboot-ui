# Menu screenshots

These are unedited in-game PNG captures from Dolphin 2606a on 2026-09-12,
built with `make preview-build` from the interface source tagged `v0.3.0-ui.2`
(`3c34985d0fcd8850df3198d16e08c22093827e66`).

- `menu-grid.png`: the resting grid and selected-game preview.
- `c-stick-inspection.png`: the same selection with C-stick pitch/yaw applied;
  the grid and details stay fixed.

The preview uses synthetic game banners. These screenshots document the UI,
not real game artwork, SD access, launching, or a hardware capture. The PNGs
retain Dolphin's native 592 × 455 screenshot dimensions and contain no desktop
or emulator-window controls. No game image, Swiss executable, or IPL dump is
included in this directory.
